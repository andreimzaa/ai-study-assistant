# ai-study-assistant
An open-source study tool that turns lecture notes and PDFs into active-recall quizzes, with every answer grounded in the source text. 
Built for the **Hacktoberfest MLH x MSJC CSC Mini Hackathon 2026**

## The Problem
Many students truggle to turn dense course materials into study tools. Making flashcards can take too much time and many AI tools produce questions that aren't tied to the original material from the course. Leading to students not knowing whether the answer is correct or not. 

## Features
- **Document Ingestion** Upload lecture PDFs or Markdown Notes
- **Retrieval** Documents are chunked and embedded in an in-memory vector store.
- **Structured Quizzes** Multiple choice questions returned as validated JSON, with explanations.
- **Citation** Each answer links back to the source page and passage for verification and note taking. 

## Open-weight AI
- **Model: ** [Llama 3.2 3B](https://ollama.com/library/llama3.2) 
- **Embeddings:** [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) 
- **Dependencies:** Streamlit, ChromaDB, PyPDF, Ollama Python client.

## How Open-Weight AI Is Used 
The quiz generator runs on [BLANK]. Every question, answer option, explanation, and citation is generated by the model. The app cannot function without it. Everything runs locally so the student notes never leave the user's machine. 

## Limitations
- Text-based PDFs only (no OCR)
- In-memory index resets on restart
- Quiz quality depends on the 3B model and the source notes
